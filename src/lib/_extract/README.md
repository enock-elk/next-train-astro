# `_extract` — dormant SPA fragments

These files are **not imported** by the app. They are leftovers from the
one-time `assemble-live-board.mjs` scrape that produced `live-board.js` and
`live-board-ui.js`.

Edit the assembled modules under `src/lib/` directly. Re-running the assembler
requires `FORCE_ASSEMBLE=1` and will wipe hand patches.
