nexttrain-og — what YOU still need to do
========================================

Code is ready. DNS is already orange-clouded on Cloudflare.
Your only remaining job is to deploy this Worker once from your computer.

1. Open a terminal in the repo, then:

   cd workers/nexttrain-og
   npm install
   npx wrangler login
   npm run deploy

2. Smoke-test in the browser:
   - https://nexttrain.co.za/og/health
     → should show {"ok":true,...}
   - https://nexttrain.co.za/og/timetable.png?rt=pta-pien&dir=A&d=wd
     → timetable-looking image
   - https://nexttrain.co.za/
     → normal app (still works)

3. Refresh the social preview:
   - Open https://developers.facebook.com/tools/debug/
   - Paste https://nexttrain.co.za/?rt=pta-pien&v=g&d=wd
   - Click "Scrape Again"
   - Send that link in a NEW WhatsApp chat (old chats keep the old icon)

Notes
-----
- Live files live in the metrorail-app GitHub Pages project (custom domain
  nexttrain.co.za). Preview repo next-train-astro is NOT used as origin.
- github.io/metrorail-app redirects to nexttrain.co.za — that is expected.
  The Worker does not fetch that URL for humans; it uses Cloudflare origin
  pass-through instead.
- Routes attached: / and /og/* on nexttrain.co.za and www.nexttrain.co.za
